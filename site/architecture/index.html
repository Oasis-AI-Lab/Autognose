03 Design principles

Seven rules,
no exceptions.

From the agent protocol (AGENT.md). They are constraints on every contribution, including this website.

01

Meta-knowledge first.

Nothing is built on items lacking provenance and status.

02

Evaluation first.

No capability claim without a harness that could fail.

03

One narrow wedge.

Obviously incomplete beats vaguely broad.

04

Honest uncertainty.

Where we do not know, we say so — in docs and in code.

05

Low overhead.

If provenance costs a real fraction of the query budget, the design is wrong.

06

Open core.

MIT. The public surface is the project.

07

Do not reinvent wheels.

Use the retriever, the database, and the framework that exist.

Explicit non-goals — first milestone

No consciousness, sentience, or experiential claims.

No general autonomous planning or agent runtime.

No large-scale or distributed databases.

No comprehensive cognitive architecture.

No personality or identity simulation.

No universal agent-framework integration.

The survey's eight-component system is a reference for comparison — not a build target.

No fixed state schema until OD-2 is decided.
