01 Experiments

An evaluation that
can fail honestly.

R0 builds the harness before any mechanism is compared: scenarios with ground truth by construction, baselines that catch degenerate strategies, and pre-registered expectations. R1 then asks whether any minimal mechanism changes behaviour at all.

R1 — Five experiments

Each with pre-registered hypotheses, controlled variables, and explicit failure conditions. A mechanism that fails is a reportable result, not a hidden one.

E1

Representation ablation

Does an explicit state layer change assessment quality? Mechanism A / B / C against B2 / B3 on scenarios S1–S5.

E2

Representation swap

Is persistence worth anything, or only the fields? Stateless vs persistent with the same field set.

E3

Downstream utility

Does the assessment improve the external agent's decisions, versus a score-only policy?

E4

Validity under shift

Do stated assessments still predict accuracy when the distribution shifts — paraphrase, harder gaps, mixed staleness?

E5

Cost accounting

Retrievals, tokens, latency, storage writes per query — measured, not estimated. A mechanism whose cost exceeds the budget it saves is disqualified by its own principle.

Anti-circularity controls — harness requirements

Generator and judge share no code path.

Every synthetic item carries a verifiable reason for its label.

LLM-generated labels are validated against a human-labelled holdout before the generator is trusted at all.

Every run produces a machine-readable results file; prose cites it and never replaces it.
