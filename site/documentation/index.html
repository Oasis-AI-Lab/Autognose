02 Concepts

The vocabulary.

C·1

Knowledge state

What the system maintains about its own knowledge: whether the evidence is sufficient, contradictory, or stale. The field set is an open decision, deliberately unresolved because it becomes the public API.

C·2

Action vocabulary

One decision per question: answer, retrieve more, ask, abstain, flag for review. "Unknown" is a legal assessment — saying so carries no penalty.

C·3

Assessment quality vs downstream utility

Two metric families, reported separately, always. Conflating them is the failure mode the experiment plan is designed to make visible.

C·4

Status labels

Every statement in the program documents carries exactly one: established, implemented, experimental, proposed, open question, or recorded decision. Nothing in this repository is currently Implemented.

C·5

Capability · mechanism · behaviour · evaluation

Four analytical separations used throughout the documents. Recognising a boundary is a capability; storing it explicitly is one mechanism among several; declining is a behaviour; measuring all of it is evaluation. The survey's original six "core characteristics" mix these four — that conflation is documented, not inherited.
